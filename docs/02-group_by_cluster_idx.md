# `group_by_cluster_idx`

```python
group_by_cluster_idx(classifications: NDArray[clust_idx_t]) -> list[list[int]]
```

Group sample indices by cluster label.

This helper converts a one-dimensional array of cluster assignments into an explicit list of clusters, where each cluster is represented as a list of sample indices belonging to it.

It is designed for SPORE-style labels, where labels are integer cluster indices and noise, when present, is encoded as `-1`.

---

## Labeling Assumptions

This function assumes that cluster labels:

* are integers;
* are nonnegative cluster indices, optionally including the noise label `-1`;
* are bounded by a reasonably small maximum label;
* are generated by SPORE or another algorithm with a compatible labeling scheme.

Labels are used directly as list indices. No remapping, hashing, or validation is performed.

The noise label `-1` is handled through Python's negative indexing. When `-1` is present, an extra bucket is allocated so noise samples are collected in the final returned cluster.

This function is not intended for arbitrary clustering outputs with string labels, multiple negative labels, or very large sparse labels. Sparse integer labels such as `{0, 2, 7}` can work, but they create empty intermediate buckets that are removed afterward.

---

## Parameters

### `classifications : NDArray[clust_idx_t]`

One-dimensional array of length `N`, where `classifications[i]` is the cluster label assigned to sample `i`.

---

## Returns

### `list[list[int]]`

A list of clusters, where each cluster is represented by a list of sample indices.

* Empty clusters are omitted.
* Clusters are ordered by increasing nonnegative cluster index.
* If the noise label `-1` is present, the noise cluster appears last.
* If `classifications` is empty, an empty list is returned.

---

## Example

```python
import numpy as np

classifications = np.array([0, 0, 1, -1, 1])
clusters = group_by_cluster_idx(classifications)

print(clusters)
```

Output:

```text
[[0, 1], [2, 4], [3]]
```

Here:

* samples `0` and `1` belong to cluster `0`;
* samples `2` and `4` belong to cluster `1`;
* sample `3` belongs to the noise cluster, encoded as `-1`.
